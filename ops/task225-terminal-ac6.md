# Terminal evidence tiers and independent expectations

The AC6 reviewer consumes the immutable joined terminal provider. It explicitly
separates five production-source rules, four shipped-browser journeys with real
HTTPS/Socket.IO/MongoDB, and direct invocations of retained listeners. The last
are source controls even though they execute inside a browser. The network
replay instead appends a previously received packet to an actual upstream HTTPS
response and requires a matching capture and real client dispatch.

`terminal_ac6_policy.json` binds the acquisition code paths inspected for this
review. Initial fixture authoring precedes service startup and admission; it
is not natural-game evidence. Browser inputs perform all selected live actions.
The capture adapters read own storage and explicitly pinned private getters.
They retain native timing, replace mutating legacy observations, preserve the
original assertions, and make no AI or runtime-board substitutions. UI drawing
instrumentation forwards the native fillText call. Polling and local TLS
preloads retain real application handlers. Deliberate reload cancellation is
recorded and checked, not a hidden retry.

These source reviews alone cannot establish coverage. `review_terminal_tiers.js`
also binds original receipts/preloads, manifest cases, required assertions,
participant/session/game identities, service processes, received/replayed
packets, browser inputs, and the three independently recomputed oracle reviews.
AC1 derives flooding, upkeep, starvation and outcomes from initial boards; AC2
compares raw terminal state across authenticated replay and reconnect; AC3
independently computes the first legal move from geometry and checks full state,
retained identities, named callbacks and persistence. Oracle source hashes and
separate output digests are retained in the AC6 report.

The AC6 selection owns a separate provider key. Its gate first executes the
existing AC1–3 consumer, then compares AC6 review absent/present using identical
provider inputs and the same current source baseline. Only AC6 may change;
all other criteria, research gaps, public deferrals and eight self owners must
remain identical. Missing, changed, wrong-context, wrong-run, mislabeled,
unbound or partial proof is rejected. A successful scoped comparison remains
insufficient for the full TASK-225 audit or status `to-verify`.


This starts no gameplay services and never edits historical provider evidence.
The runner enforces the cumulative 55-minute stop and 60-minute cleanup limit,
records actual command exits, and leaves full-invocation artifacts explicitly
incomplete. The independently observed OS-zero consumer and runner receipts,
final hash audit and exact disposition comparison are required before selecting
its successor. Existing AC4 acquisition-location, AC7 map-size and original
outer-receipt gaps remain separate prerequisites.
